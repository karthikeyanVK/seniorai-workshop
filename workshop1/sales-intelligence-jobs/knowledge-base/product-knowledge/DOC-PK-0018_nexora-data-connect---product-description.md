# Nexora Data Connect - Product Description

**Nexora Data Connect** (Integration). Bi-directional CRM and ERP integration.

Pricing: Flat Fee, list $1,100.00 per unit per month, billed annual (product_id 10).

Key capabilities:
- Salesforce bi-directional sync
- NetSuite and SAP invoice sync
- 15-minute scheduled sync

Limitation: Implementation takes 2-4 weeks.
