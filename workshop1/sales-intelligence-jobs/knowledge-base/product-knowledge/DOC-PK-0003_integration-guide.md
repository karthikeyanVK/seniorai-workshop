# Integration Guide

Native connectors: Salesforce (bi-directional, via Data Connect), HubSpot (one-way), Microsoft Dynamics (one-way), NetSuite and SAP (invoices and accounts), Slack and Microsoft Teams (alerts), Zoom and Google Meet (conversation intelligence). Data Connect includes scheduled sync every 15 minutes, a field mapping UI and conflict rules. Standard integrations on Professional use the REST API; Starter has no API access. Typical implementation: 2-4 weeks for Data Connect.
