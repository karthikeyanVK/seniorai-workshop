# Nexora Forecast Pro - Product Description

**Nexora Forecast Pro** (Analytics). Weekly forecast snapshots with rep and manager overrides.

Pricing: Flat Fee, list $900.00 per unit per month, billed quarterly (product_id 3).

Key capabilities:
- Commit / best case / pipeline rollups
- Slippage detection
- Forecast vs actual tracking

Limitation: Weekly snapshots only.
