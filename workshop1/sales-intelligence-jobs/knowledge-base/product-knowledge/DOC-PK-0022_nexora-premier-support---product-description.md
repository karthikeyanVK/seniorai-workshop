# Nexora Premier Support - Product Description

**Nexora Premier Support** (Services). 24x7 premium support and named success manager.

Pricing: Flat Fee, list $1,500.00 per unit per month, billed annual (product_id 14).

Key capabilities:
- 1-hour P1 response
- Named CSM
- Quarterly reviews

Limitation: Excludes custom development.
