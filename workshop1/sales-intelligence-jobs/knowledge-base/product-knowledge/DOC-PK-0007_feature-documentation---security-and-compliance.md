# Feature Documentation - Security and Compliance

Security & Compliance Pack adds SOC 2 reports, audit log export, field-level encryption, IP allow-listing and SCIM provisioning. SAML SSO itself is part of Professional/Enterprise plans, not the Pack. EU data residency (Frankfurt) is enabled per tenant by Support and requires the Enterprise plan; migration takes about 10 business days.
