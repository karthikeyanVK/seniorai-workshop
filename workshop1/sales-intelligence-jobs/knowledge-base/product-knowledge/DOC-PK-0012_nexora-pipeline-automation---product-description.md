# Nexora Pipeline Automation - Product Description

**Nexora Pipeline Automation** (Automation). Rules engine for follow-ups, stale-deal alerts and approval routing.

Pricing: Flat Fee, list $1,200.00 per unit per month, billed quarterly (product_id 4).

Key capabilities:
- Stale opportunity alerts
- Discount approval routing
- Task automation

Limitation: Maximum 200 active rules per tenant.
