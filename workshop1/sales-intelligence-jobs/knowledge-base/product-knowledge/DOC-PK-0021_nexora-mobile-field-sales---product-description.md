# Nexora Mobile Field Sales - Product Description

**Nexora Mobile Field Sales** (Core Platform). Mobile selling app.

Pricing: Per User, list $18.00 per unit per month, billed monthly (product_id 13).

Key capabilities:
- Offline read access
- Call and visit logging
- Push alerts

Limitation: Offline edit not supported.
