# Nexora Sales Cloud - Product Description

**Nexora Sales Cloud** (Core Platform). Core CRM-connected selling workspace: pipeline, accounts, activities and revenue views.

Pricing: Per User, list $95.00 per unit per month, billed annual (product_id 1).

Key capabilities:
- Pipeline board with stage probabilities
- Account and contact timeline
- Plan-based SSO, API and audit features

Limitation: Starter plan excludes SSO and API.
