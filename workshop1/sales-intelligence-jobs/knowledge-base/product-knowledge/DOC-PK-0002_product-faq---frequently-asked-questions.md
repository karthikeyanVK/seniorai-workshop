# Product FAQ - Frequently Asked Questions

**Does Nexora support SAML SSO?** Yes, on Professional and Enterprise plans (included, enabled by an admin in Security Settings). Starter does not include SSO.
**Can we sync bi-directionally with an external CRM?** Yes via Nexora Data Connect (separate module).
**Is there EU data hosting?** Yes, Frankfurt region, generally available 2026-09-15, Enterprise plan only. APAC (Sydney) is planned for Q1 2027; there is no India region today.
**Can we export data?** Yes, CSV and API on Professional and above.
**Is there a mobile app?** Nexora Mobile Field Sales (iOS/Android).
