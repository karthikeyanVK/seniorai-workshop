# Nexora Contract Hub - Product Description

**Nexora Contract Hub** (Core Platform). Contract repository and clause tracking.

Pricing: Flat Fee, list $800.00 per unit per month, billed annual (product_id 6).

Key capabilities:
- Renewal date tracking
- Clause library
- Redline comparison

Limitation: No native e-signature.
