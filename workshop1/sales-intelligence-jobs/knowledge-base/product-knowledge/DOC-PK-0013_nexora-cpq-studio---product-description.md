# Nexora CPQ Studio - Product Description

**Nexora CPQ Studio** (Core Platform). Configure-price-quote for guided proposals.

Pricing: Per User, list $45.00 per unit per month, billed annual (product_id 5).

Key capabilities:
- Quote templates
- Discount guardrails
- E-sign handoff

Limitation: Single currency per quote.
