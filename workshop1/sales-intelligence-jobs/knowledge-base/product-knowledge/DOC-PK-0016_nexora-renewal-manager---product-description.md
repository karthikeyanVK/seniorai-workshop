# Nexora Renewal Manager - Product Description

**Nexora Renewal Manager** (Customer Success). Renewal workflow from 120 days out.

Pricing: Flat Fee, list $700.00 per unit per month, billed quarterly (product_id 8).

Key capabilities:
- Renewal calendar
- Quote generation
- Escalation triggers

Limitation: Works on Nexora subscriptions only.
