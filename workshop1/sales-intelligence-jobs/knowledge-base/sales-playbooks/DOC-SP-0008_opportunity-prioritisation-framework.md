# Opportunity Prioritisation Framework

Rank open opportunities weekly by **Expected Value = deal_value x stage probability**, then adjust: +20% if a decision maker was met in the last 14 days, -30% if no activity in 21 days, -20% if the same objection is unresolved after two calls. Work top-down: no rep should carry more than 25 open opportunities; above that, the regional manager must redistribute. Deals with an expected close date in the past are reviewed first - either re-date with a reason or close as lost.
