# Upsell and Cross-sell Guide

Which module to recommend: usage above 90% on Starter -> Professional upgrade (SSO, API, more seats). Heavy spreadsheet exports -> Revenue Analytics. Manual forecast calls -> Forecast Pro. Customers asking for a CRM sync -> Data Connect. Security questionnaires or audit requests -> Security & Compliance Pack. Always confirm what is already included in their plan before proposing an add-on - customers have asked for features they already own.
