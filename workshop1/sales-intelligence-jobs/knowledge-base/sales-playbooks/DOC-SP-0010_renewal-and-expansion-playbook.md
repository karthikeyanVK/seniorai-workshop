# Renewal and Expansion Playbook

Start the renewal motion 120 days before renewal_date. Cadence: 120d health review, 90d value review with the sponsor, 60d renewal quote, 30d paperwork. If churn_probability >= 0.45 or usage has fallen two snapshots in a row, escalate to the regional manager and involve Customer Success. Expansion signals: usage > 90%, plan seat limits reached, requests for features in a higher plan. Cross-sell order of preference: Data Connect, Revenue Analytics, Conversation Intelligence, Security & Compliance Pack.
